# Qubit Superposition Classical Bit Comparison

This Python script illustrates the fundamental difference between classical bits and quantum qubits, focusing on the concept of superposition. It defines a simplified `Qubit` class that can exist in a probabilistic combination of 0 and 1 until measured, contrasting it with a classical bit's definitive state. The example demonstrates how repeated measurements of a qubit in superposition yield probabilistic outcomes, a core principle that allows quantum computers to perform computations fundamentally differently from classical ones, with implications for cryptography.

## Language

`python`

## How to Run

Run the script from your terminal using Python:
`python main.py`
